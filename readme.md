# Обработка изображений — Задание 1

## Описание

В работе выполняется обработка изображения `sar_1_gray.jpg` в оттенках серого.

1. Загрузка изображения `sar_1_gray.jpg` в оттенках серого.
2. Построение гистограммы изображения.
3. Реализация гамма-коррекции для `γ < 1` и `γ > 1`.
4. Сравнение исходного и скорректированных изображений с использованием MSE и SSIM.
5. Реализация статистической коррекции на основе изображения `eq_gray`.
6. Проверка пороговой фильтрации с различными значениями порога.
7. Дополнительно выполнено сравнение нескольких режимов пороговой обработки OpenCV.

## Запуск

```bash
pip install -r requirements.txt jupyterlab
jupyter lab
```

## Зависимости

Все необходимые Python-библиотеки указаны в `requirements.txt`.
